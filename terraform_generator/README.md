# VibeCoder Terraform Generator

This module generates Terraform configuration files for VibeCoder projects, specifically for EC2 instances. It analyzes the project report generated by VibeCoder and creates appropriate Terraform configurations.

## Features

- Analyzes VibeCoder project reports
- Generates Terraform configurations for EC2 instances
- Supports multiple EC2 instances
- Configurable output directory
- Validates project reports and configurations

## Prerequisites

- Python 3.7+
- Terraform CLI
- AWS credentials configured

## Installation

1. Ensure you have Python 3.7+ installed
2. Install required Python packages:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Generate a project using VibeCoder
2. Run the Terraform generator:
   ```bash
   python -m terraform_generator.src.main --report path/to/project_report.json --output-dir terraform_output
   ```

### Command Line Arguments

- `--report`: Path to the VibeCoder project report JSON file (required)
- `--output-dir`: Directory where Terraform files will be generated (default: terraform_output)

## Generated Files

The generator creates the following Terraform files:

- `main.tf`: Main Terraform configuration
- `variables.tf`: Variable definitions
- `outputs.tf`: Output definitions

## Applying the Configuration

1. Navigate to the output directory:
   ```bash
   cd terraform_output
   ```

2. Initialize Terraform:
   ```bash
   terraform init
   ```

3. Review the planned changes:
   ```bash
   terraform plan
   ```

4. Apply the configuration:
   ```bash
   terraform apply
   ```
