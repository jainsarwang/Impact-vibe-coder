# Sorting Algorithm Visualizer

## Description

This project is a web-based visualizer for various sorting algorithms. It allows users to generate random numbers and then visualize the sorting process step by step.

## Features

-   Generates random numbers within a user-defined range.
-   Visualizes the following sorting algorithms:
    -   Bubble Sort
    -   Insertion Sort
    -   Selection Sort
    -   Merge Sort
    -   Quick Sort
-   Displays the steps of the sorting process.

## Technologies Used

-   Python
-   Flask
-   HTML
-   CSS
-   JavaScript
-   Chart.js

## Setup

1.  **Install Python dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

2.  **Run the Flask application:**

    ```bash
    python app.py
    ```

3.  **Open the application in your web browser**

    Navigate to `http://127.0.0.1:5000/`.

## Usage

1.  Enter the desired number of elements, minimum value, and maximum value.
2.  Click the "Generate Numbers" button to generate a list of random numbers.
3.  Select a sorting algorithm from the dropdown menu.
4.  Click the "Sort" button to start the visualization.
5.  The visualization will display the steps of the sorting algorithm.
