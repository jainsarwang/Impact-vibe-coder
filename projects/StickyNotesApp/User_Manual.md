# Sticky Notes App - User Manual

## Overview

The Sticky Notes App is a simple web application that allows you to create and save sticky notes. These notes persist even after you refresh the page, thanks to the use of local storage.

## Features

*   **Add Notes:** Type your note in the input box and click the "Add Note" button to create a new sticky note.
*   **Persistent Storage:** Notes are saved in your browser's local storage, so they will be there even after you close and reopen the page.
*   **Simple Styling:** The notes are styled to look like simple sticky notes with a yellow background.

## How to Use

1.  **Open `index.html` in your browser.** You can do this by double-clicking the file or by opening it through your browser's "Open File" option.
2.  **Type your note:** In the input box, type the text you want to save as a sticky note.
3.  **Click "Add Note":** Click the "Add Note" button to create the sticky note. The note will appear in the notes area.
4.  **Refresh the page:** Refresh the page to confirm that the notes persist.

## Files

*   `index.html`: The main HTML file that defines the structure of the web page.
*   `style.css`: The CSS file that styles the web page and the sticky notes.
*   `script.js`: The JavaScript file that handles adding notes, saving them to local storage, and loading them on page load.

## Development

This application uses basic HTML, CSS, and JavaScript. No external libraries are required.
