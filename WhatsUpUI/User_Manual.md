# User Manual for WhatsUp UI

This document provides instructions on how to view the Figma UI design for the WhatsUp application.

## Viewing the Design

Since the design is provided in SVG format, you can view it using any web browser or image viewer that supports SVG files.

1.  **Open SVG Files:** Open each `.svg` file (e.g., `ChatScreen.svg`, `ContactList.svg`) in your web browser (Chrome, Firefox, Safari) or an image viewer like Inkscape.
2.  **Navigate Screens:** Each SVG file represents a different screen in the application.
    *   `ChatScreen.svg`: Represents the chat screen.
    *   `ContactList.svg`: Represents the contact list.
    *   `StatusUpdates.svg`: Represents the status updates screen.
    *   `Calls.svg`: Represents the calls screen.
    *   `Settings.svg`: Represents the settings screen.
    *   `Profile.svg`: Represents the user profile screen.
    *   `MainScreen.svg`: Represents the main screen with tabs for Chats, Status, and Calls.

## Additional Notes

*   The SVG files are designed to be modular and can be further customized or integrated into a Figma project for more advanced editing.
*   This UI design provides a basic representation of the WhatsUp application and can be extended with additional features and functionalities as needed.
