
# Chatbot Features

*   **Text-based Chat:** Core functionality for users to exchange text messages with the bot.
*   **Image Input & Analysis:** Users can upload images, and the bot uses Gemini to analyze and respond.
*   **Video Input & Analysis:** Users can upload videos, and the bot uses Gemini to analyze and respond.
*   **Sentiment Analysis:** The bot analyzes the sentiment of user messages to provide more empathetic responses.
*   **Summarization:** The bot can summarize long conversations or documents provided by the user.
*   **Fast Responses:** Leverages Groq for quick text generation.
*   **User Authentication:** Secure user accounts with login/registration.
*   **Conversation History:** Users can view their past conversations with the bot.
*   **Customizable Bot Personality:** Option to choose different bot personalities or create custom ones.
*   **Context Awareness:** The bot maintains context throughout the conversation.
